# Claude Code

The fastest way to connect Typebar to Claude Code is the official plugin — it bundles the MCP server (38 tools), the 4 workflow prompts, and the auto-loading skill in one install. Manual MCP config also works as a fallback.

## Install via plugin (recommended)

In a Claude Code session, add the Typebar marketplace, then install the plugin from it:

```bash
claude plugin marketplace add superdocsapp/superdocs-plugin
claude plugin install superdocs@superdocs-plugin
```

The install argument is `plugin-name@marketplace-name` (`superdocs@superdocs-plugin`), not the GitHub repo path. Passing the repo path to `install` directly (`claude plugin install superdocsapp/superdocs-plugin`) fails with "doesn't exist in marketplace". That repo path is only valid for `marketplace add`.

You'll be prompted for your Typebar API key (`sk_…`). It's stored securely in your OS keychain — never in plaintext config. Get a key from [use.typebar.ai](https://use.typebar.ai) → **Settings → API Keys → Create**. Free plan includes 500 AI operations per month.

After install:

- All 38 MCP tools are available
- 4 workflow prompts appear in your `/` slash menu (`/superdocs:draft_from_outline`, `/superdocs:edit_styled_docx`, `/superdocs:convert_format`, `/superdocs:review_contract_for_redflags`)
- The Typebar skill auto-loads when you ask document-editing questions

For full plugin reference (auto-update behavior, troubleshooting, advanced config), see [/mcp/plugin](/mcp/plugin).

## Manual setup (advanced)

If you prefer to configure the MCP server directly without the plugin (e.g., to share a `.mcp.json` across a team via project scope), run:

```bash
# Key saved by an agent sign-up:
export SUPERDOCS_API_KEY="$(jq -r .api_key ~/.superdocs/agent_credentials.json)"
# Or paste a key from Settings at a hidden prompt instead:
#   read -rs SUPERDOCS_API_KEY && export SUPERDOCS_API_KEY
claude mcp add -s user --transport http superdocs https://api.superdocs.app/mcp \
  --header 'Authorization: Bearer ${SUPERDOCS_API_KEY}'
```

The single quotes keep your shell from expanding the variable, so your config stores the reference `${SUPERDOCS_API_KEY}` and never the key. Claude Code expands it each time it connects, so **`SUPERDOCS_API_KEY` must be exported in the shell that launches `claude`**, in every new terminal: add the `export` line to your shell profile (`~/.zshrc` or `~/.bashrc`) to keep it set. If it is not set when `claude` starts, the server answers 401 naming `SUPERDOCS_API_KEY` and does not connect. On Windows `cmd.exe`, use double quotes around the header instead. User scope (`-s user`) makes the server available from every folder; use `-s local` for the current folder only, or `-s project` to share it with your repository through `.mcp.json` (only the reference is committed). To connect with no variable at all, use the [`headersHelper` form](/introduction/agent-signup#2-use-your-key).

Both `/mcp` and `/mcp/` are accepted; `/mcp` is the canonical spelling.

That installs only the MCP server (38 tools). To get the 4 prompts and the skill, you'd need to set those up separately — the plugin install above does all three in one shot.

## Verify the connection

```bash
claude mcp list
```

You should see:

```
superdocs: https://api.superdocs.app/mcp (HTTP) - ✓
```

`superdocs` is the local name the install gives the server. The server itself reports its name as Typebar (formerly SuperDocs), and existing installs need no change.

If you see `✗ Failed to connect`, restart Claude Code (`Ctrl+C` then `claude` in a new shell). MCP servers load at session startup, so a fresh session is required after `claude mcp add`.

## Test it

```bash
claude
# Then type: "Use the Typebar health tool to check the API"
```

## Example usage

Once connected, you can ask Claude Code to:

- "Create a technical specification document using Typebar"
- "Edit my Typebar session and update the introduction"
- "Upload this file as an attachment to my Typebar session"

## Running autonomously?

If you're an AI agent driving Claude Code with no human watching, you can also self-serve an account and API key in one request, then hand it to a human near your quota cap using a one-time takeover code. See [For AI Agents](/introduction/agent-signup).

## Remove the server

```bash
claude mcp remove superdocs
```
