# Typebar Developer Documentation

Official developer documentation for [Typebar](https://typebar.ai) — the AI document editing platform.

Typebar was previously called SuperDocs. Same product, same API, same keys: nothing changes for your integration. [Read about the change](https://typebar.ai/superdocs). Typebar, formerly SuperDocs, is not related to SuperDoc (superdoc.dev).

## What is Typebar?

Typebar lets AI edit documents directly — changes happen inside the document, not in a chat window beside it. Give instructions in plain English, watch edits appear in real time.

**For individuals:** Use the [web editor](https://use.typebar.ai) to create and edit any type of document with AI assistance — contracts, reports, proposals, academic papers, and more.

**For developers:** Integrate AI document editing into your own product via REST API or MCP. One API, no prerequisites, production-ready today.
